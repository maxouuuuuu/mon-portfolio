Installation serveur DHCP

Description du projet

Pour le projet de fin d'année de BTS SIO, nous devons faire le projet GSB, ça consiste à créer toute l'infrastructure réseau d'une entreprise fictive, nous nous répartissons les tâches sous forme de missions et j'ai eu pour mission de faire le DHCP de l'entreprise, le DHCP attribue des adresses IP aux machines souhaitant se connecter au réseau.

Missions réalisées

  • Création d'un serveur DHCP sur une machine Windows 2022
  • Mise en place des étendues pour chaque VLAN
  • Mise en place des pools d'adresses pour exclure les adresses de Gateway

Technologies utilisées

Windows Server 2022 DHCP

Résultats & livrables

L'intégration d'un service DHCP dans un environnement ESXi ne doit pas être traitée comme un simple détail de configuration, mais comme un choix d'architecture structurant. En abordant les problématiques d'isolation et de sécurité, nous avons défini un modèle robuste qui sépare clairement les responsabilités.
